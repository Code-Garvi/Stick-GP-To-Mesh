# Sticky GP V2.1 Changelog

[NEW] Multi-Object Collection Binding! You can now assign an entire Collection to a layer. The addon will automatically evaluate every mesh in the collection and bind your strokes across overlapping geometry seamlessly.
[NEW] N-Panel UI Mode Toggle: Layers now have a dropdown to switch between 'Object' mode and 'Collection' mode, dynamically changing the picker slot.
[MODIFIED] Raycast Binding Engine: The core python loop now supports multi-target evaluation per point. It compares distances against all meshes in the target list and assigns the point to the absolute closest surface.
[MODIFIED] Polycount Tracker: Fix Strokes now iterates over all meshes inside targeted collections, triggering auto-fix prompts if *any* mesh in the collection has its topology edited.
