# Sticky GP V2.0 (nouv) Changelog

[MAJOR ARCHITECTURE CHANGE] Completely removed the UV-mapping dependency! The addon now uses pure Barycentric Interpolation via Geometry Nodes.
[NEW] Flawless smooth stroke offsets: By directly averaging the target mesh's smooth vertex normals, strokes no longer kink or jaggedly cross polygon boundaries.
[REMOVED] 'generate_sticky_uvs' function and the hidden 'Sticky_GP_UVMap'. The addon no longer clutters your mesh with custom UV maps.
[MODIFIED] 'bind_unbound_strokes' logic: Instead of baking 2D UV coordinates into points, Python now bakes the 3 physical vertex indices of the target triangle ('bind_v1', 'bind_v2', 'bind_v3') and their mathematical weights ('bind_bary').
[MODIFIED] GN Node Compiler: Re-written from the ground up to utilize 'Sample Index' (Point Domain) for position and normal interpolation, calculating exact surface coordinates entirely mathematically.
