# Sticky GP Addon - Changelog

## V7 (Version 1.7)
- **UV Generation Fix:** Modified the `generate_sticky_uvs` function to reuse the existing `Sticky_GP_UVMap` layer instead of explicitly deleting it and recreating it.
  - *Reason:* Explicitly deleting the UV layer via `mesh.uv_layers.remove()` completely severed Geometry Node's internal memory pointer to the `Named Attribute` node. This caused `Sample UV Surface` to fail for all points outside the first mesh triangle, sending points to the origin or face 0 during UV regeneration. Reusing the layer perfectly preserves the pointer and prevents stroke breakage upon regeneration.
- **Smart Fix Strokes System:** Replaced the dangerous standalone UV button with a dynamic, automated `Fix Strokes` operator that tracks `sticky_gp_polycount` to warn users when topology shifts.
- **Multi-Frame Animation Bugfix:** Fixed a critical bug in the auto-rebind algorithm where strokes on different frames were raycast against the mesh from a single frame. The operator now explicitly changes the scene frame in Blender to match each individual Grease Pencil keyframe before binding, ensuring the character's deformed pose matches the strokes being bound.
- **Smart Visible Stroke Binding:** Rewrote the Bind and Unbind operators to dynamically calculate the active/visible Grease Pencil drawing at the current playhead, rather than blindly processing all keyframes or forcing a strict frame match. This restores the ability to draw a stroke on frame A, move its keyframe to frame B, and bind it relative to the character's pose on frame C without corrupting other keyframes.
- **UI Update:** Renamed the bind/unbind operators to "Bind Visible Strokes" and "Unbind Visible Strokes" to accurately reflect the new smart logic.
- **Documentation:** Updated documentation to reflect V6 versioning and workflow changes.

## V5 (Version 1.5)
- **Custom UV Generator:** Added the "Perfect Grid" algorithm to create isolated, non-overlapping UV squares for every polygon, avoiding Catmull-Clark subdivision distortion along UV seams.
- **Geometry Nodes Fallback:** Implemented a robust fallback system using `bind_face_idx`. If `Sample UV Surface` fails due to 32-bit floating point precision limits at polygon boundaries, it intercepts the point and samples the precise center of its parent polygon (`Sample Index`) to prevent the stroke from jumping to the origin.

## V2
- **Multi-Character Support:** Shifted target mesh data from `bpy.context.scene` directly to the `bpy.types.Object.sticky_gp_target` property, allowing individual Grease Pencil objects to track separate target meshes simultaneously.
- **Dynamic Node Groups:** Generated sandboxed, dynamically named Geometry Node modifier groups for each Grease Pencil object to allow independent Object Info targeting without modifier dictionary assignment conflicts in Blender 4.3.
